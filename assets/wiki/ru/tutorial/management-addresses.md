# Назначьте IP-адреса управления

IP-адрес идентифицирует интерфейс на уровне L3. Префикс показывает, какие адреса
доступны напрямую в той же подсети. `10.0.10.10/24` находится в `10.0.10.0/24`;
маска `/24` — `255.255.255.0`.

Назначьте контроллеру `10.0.10.10/24`, узлу ВМ — `10.0.10.11/24` на настоящих
Ethernet-интерфейсах управления. Адреса должны быть частными, разными, уникальными
в мире и находиться в одной подсети. Для этой локальной связи шлюз не нужен.

## В консоли контроллера

```sh
ip addr add 10.0.10.10/24 dev eth1
ip link set dev eth1 up
ip -br addr
```

## В консоли узла ВМ

```sh
ip addr add 10.0.10.11/24 dev eth1
ip link set dev eth1 up
ip -br addr
```

Подставляйте реальные имена интерфейсов. Они остаются нетегированными; access-порты
коммутатора выбирают VLAN 10. Поле Access VLAN сервера не создаёт тегированный
Linux-подинтерфейс. Старый адрес удаляется командой
`ip addr del АДРЕС/ПРЕФИКС dev ИНТЕРФЕЙС`.

## Сохранение для перезагрузки

Команды `ip` меняют активные настройки. На каждом сервере откройте:

```sh
nano /etc/network/interfaces
```

Для контроллера запишите:

```text
auto lo eth0 eth1
iface lo inet loopback
iface eth0 inet manual
iface eth1 inet static
    address 10.0.10.10/24
```

На узле ВМ замените адрес на `10.0.10.11/24`. Ctrl+O, Enter сохраняет файл;
Ctrl+X выходит. Примените:

```sh
systemctl restart networking
ip -br addr
```

Позже добавим публичный адрес контроллера в секцию `eth0`. Интерфейс `eth0` узла
может оставаться мостом для ВМ без IP хоста при явных правилах гостевых подсетей.

Далее: [проверьте ping](management-ping.md).
