# Соедините интерфейсы управления

Сеть позволяет устройствам обмениваться данными по рабочим соединениям. Кабель
Ethernet соединяет два порта. Коммутатор объединяет порты на **уровне L2** и
пересылает кадры внутри VLAN по MAC-адресам.

## Какие порты соединить

На каждом сервере посмотрите реальные имена интерфейсов:

```sh
ip -br link
```

В примере `eth1` используется для управления, а `eth0` — для публичной сети и
клиентских ВМ. Соедините `eth1` контроллера с `Gi1/0/1` коммутатора, а `eth1`
узла ВМ — с `Gi1/0/2`. У вашего оборудования имена могут отличаться.

Нажмите на Ethernet-разъём сервера, затем на разъём коммутатора. Сначала купите
материалы. Во время подключения можно переключать переднюю и заднюю стороны
стойки. Пассивная патч-панель допустима; LAN-розетки стоек сами не создают общую сеть.

Оба интерфейса управления должны достигать одного включённого коммутатора по
рабочим физическим линиям. Наличие кабеля не означает рабочий линк: питание,
отключённый порт или несовместимая оптика могут мешать. IP-адрес не исправляет
неработающее физическое соединение.
