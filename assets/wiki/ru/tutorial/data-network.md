# Соедините и маршрутизируйте клиентскую сеть

Управление оставьте в VLAN 10, клиентскую сеть создайте в VLAN 20. Соедините `eth0`
контроллера с `Gi1/0/3`, `eth0` узла ВМ с `Gi1/0/4`, а LAN маршрутизатора
`Gi0/1/6` с `Gi1/0/5` коммутатора.

## На коммутаторе

```text
enable
configure terminal
vlan 20
name Customers
exit
interface Gi1/0/3
switchport mode access
switchport access vlan 20
no shutdown
exit
interface Gi1/0/4
switchport mode trunk
switchport trunk allowed vlan 20
no shutdown
exit
interface Gi1/0/5
switchport mode trunk
switchport trunk allowed vlan 20
no shutdown
exit
end
write memory
```

Контроллер передаёт нетегированные кадры через access-порт. Гостевой мост узла ВМ
и маршрутизатор используют trunk с тегированной VLAN 20. Подинтерфейс
маршрутизатора принимает эти теги.

## На маршрутизаторе C1111

Подставьте WAN и шлюзы из окна IP-ДИАПАЗОНЫ:

```text
enable
configure terminal
interface Gi0/0/0
ip address 192.0.2.2 255.255.255.252
no shutdown
exit
interface Gi0/1/6
no switchport
no shutdown
exit
interface Gi0/1/6.20
encapsulation dot1q 20
ip address 203.0.113.1 255.255.255.248
exit
ip route 0.0.0.0 0.0.0.0 192.0.2.1
end
show ip route
ping 192.0.2.1
write memory
```

`no switchport` переводит гибкий LAN-порт C1111 в маршрутизируемый режим.
На другой модели выберите подходящий маршрутизируемый порт. Связанный маршрут
`/29` покрывает клиентскую сеть. Маршрут по умолчанию направляет остальные адреса
к вышестоящему шлюзу; доставка диапазона даёт оператору обратный путь к вам.

## Назначьте гостевую подсеть узлу

В **ХОСТИНГ → Узлы хостинга** выберите узел. В правилах **Подсеть ВМ → порт / VLAN**
отключите автоматический выбор существующих сетей. Добавьте купленную подсеть
`203.0.113.0/29` на `eth0` с **Tagged VLAN 20** и примените.

Кабель узла подключён к trunk; гостевой мост должен передавать теги VLAN 20.
Управление остаётся нетегированным на отдельном access-кабеле. Теги и разрешённые
VLAN должны совпадать на обоих концах.

Явное правило позволяет мосту ВМ работать без публичного IP самого узла. Шлюз
должен обнаруживаться по реальному пути через порт/VLAN; сохранённой записи мало.

Далее: [подключите витрину](storefront.md).
