# L3, IP-адреса и маршруты

**L3** передаёт IP-пакеты между сетями. Адрес `10.0.10.11/24` принадлежит
`10.0.10.0/24`. Префикс описывает IP-подсеть, VLAN — принадлежность Ethernet.
Для прямой связи должны согласоваться оба уровня.

Для получателя в своей подсети сервер использует ARP и отправляет кадр прямо
на его MAC. Для другой подсети он выбирает маршрут и обычно посылает кадр на
MAC шлюза, сохраняя **IP-адрес удалённого получателя** в пакете.

Маршрутизатор выбирает выходной интерфейс по таблице маршрутов. Побеждает самый
длинный подходящий префикс. `0.0.0.0/0` — маршрут по умолчанию для остальных
направлений. Следующий шлюз должен быть доступен.

Нужны оба направления. Default route ведёт к оператору; оператору нужен обратный
маршрут к публичному диапазону. В игре **IP-ДИАПАЗОНЫ → доставка диапазона** задаёт
этот договор. Она не настраивает ваши интерфейсы и маршрутизатор. Покупка диапазона
сама не создаёт связь.

Частные RFC1918-адреса, например `10.0.10.0/24`, подходят для управления. Публичные
гости используют свободные адреса купленных диапазонов. Неявный NAT здесь не
создаётся: руководству нужна явная публичная маршрутизация.

Команды Linux:

```sh
ip -br addr
ip route
ip route get 8.8.8.8
traceroute 8.8.8.8
```

На маршрутизаторе: `show ip interface brief`, `show ip route`, `traceroute АДРЕС`.
Пример: [клиентская сеть](../tutorial/data-network.md).
