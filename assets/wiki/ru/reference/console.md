# Работа с консолями

Выберите включённое устройство для консоли или откройте её отдельное окно.
Серверы используют симулируемый Linux, коммутаторы и маршрутизаторы — команды IOS.
Команда выполняется на текущем устройстве консоли.

Tab дополняет команды; `?` в IOS показывает доступные варианты, `help` в Linux —
поддерживаемые команды. Блоки Wiki можно копировать и вставлять, предварительно
подставив свои адреса и интерфейсы. Копирование не запускает команды.

IOS: `enable` — привилегированный режим, `configure terminal` — настройка,
`interface ИМЯ` — интерфейс. `exit` поднимается на уровень, `end` возвращает
привилегированный режим, `write memory` сохраняет настройки для reload.

Linux: `ip` меняет активную сеть, `/etc/network/interfaces` и
`systemctl restart networking` задают настройки для reboot. В nano Ctrl+O, Enter
сохраняет файл, Ctrl+X выходит.

Можно пользоваться GUI. Проверки оценивают результат в мире, а не факт ввода
строго заданной последовательности. Консоль поддерживает команды игры и не
запускает произвольное программное обеспечение настоящей ОС.
