# L2, коммутаторы и VLAN

**L2** передаёт Ethernet-кадры в локальной сети. Интерфейс имеет MAC-адрес.
Коммутатор изучает доступность MAC через порты и пересылает кадры подходящим
получателям. Широковещательные кадры, включая ARP, остаются внутри своей VLAN.

VLAN — отдельный широковещательный домен. VLAN 10 и VLAN 20 могут работать на
одном устройстве, оставаясь отдельными сетями. Для IP-связи между ними нужна
маршрутизация с разрешёнными путями.

Access-порт обслуживает одну VLAN. Обычно сервер отправляет нетегированные кадры,
а коммутатор относит их к access VLAN. Trunk переносит несколько VLAN с тегами
802.1Q. Allowed list ограничивает VLAN, а native VLAN обслуживает разрешённые
нетегированные кадры.

Оба конца должны согласоваться. Тегированный сервер на access-пути, отсутствие
VLAN в allowed list или разные native VLAN ломают связь при рабочем кабеле.
Создание VLAN само не назначает порты или IP-адреса.

Команды коммутатора:

```text
show vlan brief
show interfaces status
show interfaces Gi1/0/1 switchport
show interfaces trunk
```
