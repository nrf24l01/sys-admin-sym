# Сети и физические соединения

Сеть позволяет устройствам обмениваться данными по соединённым путям. Порт Ethernet
— разъём устройства, кабель соединяет два разъёма. Рабочий **линк** требует
совместимого оборудования, включённых интерфейсов и питания.

Коммутатор соединяет локальные Ethernet-устройства, маршрутизатор — IP-сети,
сервер запускает сервисы. Патч-панель пассивна: она организует кабели, не заменяя
коммутатор и не усиливая оптический сигнал.

Обычная схема небольшого провайдера: внешний канал → маршрутизатор → коммутатор
→ серверы. Управление и клиенты могут использовать один коммутатор с разными VLAN.
Кабели питания подключаются отдельно от Ethernet.

Проверяйте снизу вверх: питание, физический линк, VLAN, IP-адреса, маршруты,
сервис. Верхние уровни не исправляют отсутствие нижних.

Читайте [L2 и VLAN](layer2-vlans.md), затем [L3 и маршруты](layer3-routes.md).
