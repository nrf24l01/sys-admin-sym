# Настраиваемое серверное оборудование

Шасси Dell PowerEdge R360 из магазина и его процессоры/DIMM используют
`assets/equipment/server_parts.json`. JSON из установленного файла
переопределяет встроенные значения по умолчанию один раз при запуске.
Неверная топология или отсутствующие ограничения вызывают ошибку
с именем файла и причиной. После редактирования конфигурации оборудования
перезапустите приложение.

## Ограничения каталога

Шасси задаёт процессорные сокеты, идентификаторы поддерживаемых процессоров,
максимальный TDP процессора, требование одинаковых процессоров и возможность
замены компонентов при включённом питании. Отсеки накопителей задают
свои интерфейсы. Слоты PCIe задают связанный с ними процессор, число
электрических линий, физическую ширину разъёма и поколение. Существующий
профиль `power` в `server_config.json` определяет мощность и эффективность
преобразования каждого БП. Оба задних ввода питания подключаются независимо;
о переключении между вводами, поведении при загрузке, настройках JSON
и преобразовании сохранений см. [интерфейсы и резервирование питания](SERVER_INTERFACES_AND_POWER.md).

Объект `memory` шасси задаёт суммарную ёмкость, число каналов на процессор,
число DIMM на канал, именованную топологию разъёмов, предпочтительный порядок
заполнения, допустимое число DIMM, правила смешивания и матрицу поддерживаемых
модулей и скоростей. У каждого процессора есть собственные ограничения
`memory` по поддерживаемым типам, ёмкости, каналам, общему числу DIMM,
числу DIMM на канал и скорости, а также максимальное число сокетов
и ограничения PCIe. Модули ОЗУ задают ёмкость, тип, номинальную скорость
передачи, число рангов и напряжение. Совместимость учитывает ограничения
и шасси, и процессора. В Rust нет зашитых значений ёмкости или числа каналов
для отдельных моделей.

Пример настроек памяти шасси:

```json
{
  "max_capacity_gb": 128,
  "channels_per_cpu": 2,
  "dimms_per_channel": 2,
  "identical_dimms": true,
  "supported_dimm_counts": [1, 2, 3, 4],
  "population_order": [0, 1, 2, 3],
  "slots": [
    { "name": "A1", "cpu_socket": 0, "channel": 0, "position": 0 },
    { "name": "A2", "cpu_socket": 0, "channel": 1, "position": 0 },
    { "name": "A3", "cpu_socket": 0, "channel": 0, "position": 1 },
    { "name": "A4", "cpu_socket": 0, "channel": 1, "position": 1 }
  ],
  "supported_modules": [
    {
      "capacity_gb": 16,
      "ranks": 1,
      "voltage_mv": 1100,
      "rated_speeds_mt_s": [4800, 5600],
      "operating_speeds_mt_s": [4400, 4000]
    },
    {
      "capacity_gb": 32,
      "ranks": 2,
      "voltage_mv": 1100,
      "rated_speeds_mt_s": [4800, 5600],
      "operating_speeds_mt_s": [4400, 3600]
    }
  ]
}
```

Индекс `operating_speeds_mt_s` соответствует числу DIMM на канал
(первый элемент = 1 DPC). Рабочая скорость — наименьший предел
установленных модулей, процессора и заполненных каналов. Основной
разъём должен быть заполнен раньше следующего разъёма в том же канале.
Автоматическое размещение следует предпочтительному порядку; явная
установка и снятие используют индексы физических слотов. Проверка
совместимости в магазине и установка используют одинаковые проверки.

## Официальная конфигурация, представленная в игре

R360 использует один процессор, четыре слота ECC UDIMM и до 128 ГБ памяти.
[Характеристики памяти Dell](https://www.dell.com/support/manuals/en-us/poweredge-r360/r360_ism/memory-specifications?guid=guid-c2545624-b0c6-4d75-b6b0-2e504269f98e&lang=en-us).
Его два канала соответствуют A1/A3 и A2/A4. Один DIMM на канал работает
на 4400 MT/s; два — на 4000 MT/s для одноранговых модулей 16 ГБ
или 3600 MT/s для двухранговых модулей 32 ГБ.
[Матрица памяти Dell](https://www.dell.com/support/manuals/en-us/poweredge-r360/r360_ism/system-memory-guidelines?guid=guid-b0770d5a-3a3e-490f-ad3f-46377742d34a&lang=en-us).
Совпадение характеристик модулей и сбалансированное заполнение каналов
следуют [рекомендациям Dell по установке](https://www.dell.com/support/manuals/en-us/poweredge-r360/r360_ism/general-memory-module-installation-guidelines?guid=guid-29c7e354-ec34-4d1a-9452-64dbde9e0232&lang=en-us).

Xeon E-2434 имеет четыре ядра и восемь потоков, поддерживает один сокет,
два канала памяти, максимум 128 ГБ, DDR5-4800 и 20 линий PCIe.
[Характеристики процессора Intel](https://www.intel.com/content/www/us/en/products/sku/236192/intel-xeon-e2434-processor-12m-cache-3-40-ghz/specifications.html),
[правила установки DIMM Intel](https://www.intel.com/content/www/us/en/support/articles/000096438/processors/intel-xeon-processors.html).
Моделируемый двусторонний райзер типа butterfly имеет два электрических
слота Gen4 x8 с физическими разъёмами x8/x16.
[Конфигурация райзера Dell](https://www.dell.com/support/manuals/en-us/poweredge-r360/r360_ism/expansion-card-installation-guidelines?guid=guid-9ffebd78-0ef4-4614-b698-c450c609054f&lang=en-us).
Карты PCIe согласуют наименьшее поколение среди процессора, слота и карты.

Инспектор показывает фактический и максимальный объём в ГБ, использование
каналов, рабочую скорость и размещение DIMM. `lscpu` сообщает топологию
и ограничения процессора; `free -h` — установленную ёмкость. Существующая
взвешенная оценка памяти остаётся метрикой игровых ресурсов. Тайминги
прошивки, обучение памяти, поведение turbo и измеренная производительность
нагрузок не эмулируются. Кривые мощности компонентов остаются
настраиваемыми оценками.

## Совместимость сохранений

Существующие идентификаторы компонентов и инвентари сохраняются.
Старые сохранения без `ram_slot_indices` получают назначения слотов
в настроенном порядке заполнения. Снятие DIMM сохраняет расположение
остальных модулей. Несовместимые сохранённые сборки остаются в сохранении,
но не могут включиться, пока их конфигурация не будет исправлена.
Новые DIMM 32 ГБ используют существующую универсальную иллюстрацию ОЗУ.
